# Final Submission Checklist

Complete every item before submitting.

## App
- [ ] Cloudinary account is configured.
- [ ] `snapsell_unsigned` preset exists and is set to **Unsigned**.
- [ ] App successfully uploads a test image.
- [ ] Optimized URL opens and image preview displays.
- [ ] App works on the deployed public URL.

## GitHub
- [ ] Public repository created.
- [ ] `index.html`, `README.md`, `DEMO_SCRIPT.md`, `SUBMISSION_CHECKLIST.md`, and `LICENSE` committed.
- [ ] No API secret, password, or private key committed.
- [ ] README contains the actual live demo URL, if deployed.

## Demo video (2–4 minutes)
- [ ] Show the app and explain the problem.
- [ ] Perform an actual upload.
- [ ] Show original and optimized delivery preview.
- [ ] Open or copy the Cloudinary delivery URL.
- [ ] Explain which Cloudinary features are used.
- [ ] Do not claim features that are not implemented.
- [ ] Upload the video to the platform requested by the hackathon.

## Hackathon portal
- [ ] Paste the public GitHub repository URL.
- [ ] Paste the live demo URL, if the form supports it.
- [ ] Add the demo video link.
- [ ] Complete the mandatory feedback survey: https://cld.media/hackathon-survey
- [ ] Verify all links are accessible without logging in.
- [ ] Submit before the portal freezes.

**Important:** Creating this ZIP does not submit the project automatically. You must upload/push the files and complete the hackathon form yourself.
